# Apteryx Solutions Website

A responsive, static company website for Apteryx Solutions.

## Deploy
This is a static website. Deploy the repository root to Vercel with framework preset **Other** and no build command. The root contains `index.html`.

## Contact form note
The enquiry form opens the visitor's email application using a prefilled message to team.apteryx@gmail.com. It does not submit to a server or store form data online.

## Before launch
- Verify all contact details.
- Review service descriptions and business claims.
- Add real client stories or testimonials only with permission.
- Add a custom domain when ready.
- Add a privacy policy reviewed for your actual data practices if you use analytics or a hosted form service.
